# LinkedIn

- **Easy Apply** opens a dialog of several short steps: contact, résumé, a few screening questions, review, then
  "Submit application".
  - The contact step usually shows the user's details already. Take the suggestions; don't retype what's already there.
  - The résumé step lists every résumé ever uploaded, several with the same name and years old. Never pick one off
    that list. Take the suggestion on the "Upload resume" field (`value: "resume"`): it uploads the user's current
    résumé, which LinkedIn then selects. Never press a résumé from the dialog's buttons.
  - Screening questions are mostly yes/no and years of experience. Ground the years in the résumé, counting by the
    role's dates, and use the field's own options.
  - "Review" is a Next step, not the submit. The last control is "Submit application".
- **"Apply" (not Easy Apply)** leaves LinkedIn for the company's site. The run carries on there as a career site.
- **Logged out** (a sign-in page or "authwall"): the run is skipped. The user logs in once in the agent's Chrome.
- **A security checkpoint** counts as a captcha wall: skip.
