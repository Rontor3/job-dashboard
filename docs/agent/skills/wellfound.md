# Wellfound

- **The form:** "Apply" opens one dialog. It has the user's location (an autocomplete), a relocation question, and
  usually an optional "What interests you about working for this company?" box. The last control is "Send application".
- **The interest box:** it is optional, but "Send application" can stay disabled until it is filled. Write two or
  three honest sentences linking the user's résumé to this company's product, from the job description, with
  `source: "agent"`.
- **Location:** use the profile's city, or the job's location when the user is willing to relocate.
- **Logged out:** the dialog shows a sign-up form instead. The run is skipped; the user logs in once in the agent's Chrome.
- **A submit counts** only when Wellfound itself confirms it, and the tool checks that for you.
